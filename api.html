VintHub REST API Reference

CVE Intelligence Lookup API

GET https://cve.vinthub.io/{year}/{cve_id}.json

  • ✓ Input: year (YYYY), CVE ID
  • ✓ Output: Consolidated vulnerability intelligence for the specified CVE ID 
curl -X GET "https://cve.vinthub.io/2026/CVE-2026-63030.json" \
  -H "Accept: application/json"
import requests

cve_id = "CVE-2026-63030"
url = f"https://cve.vinthub.io/{cve_id.split('-')[1]}/{cve_id}.json"

response = requests.get(url)
data = response.json()

print(f"SSVC Decision: {data['ssvc']['decision']}")
print(f"EPSS Probability: {data['epss']['score']}")
print(f"PoCs Found: {len(data['pocs'])}")
SAMPLE JSON RESPONSE OBJECT:
{ "id": "CVE-2026-63030", "cvss_score": 9.8, "cisa_kev": true, "epss_score": 0.97271, "ssvc_decision": "ACT", "pocs_count": 77 }

Daily Threat News Feed API

GET https://news.vinthub.io/{year}/{month}/{date}.json

  • ✓ Input: year (YYYY), month (MM), date (YYYY-MM-DD)
  • ✓ Output: Daily CVE news 
curl -X GET "https://news.vinthub.io/2026/10/2026-10-19.json" \
  -H "Accept: application/json"
import requests

date_str = "2026-10-19"
year, month, _ = date_str.split("-")
url = f"https://news.vinthub.io/{year}/{month}/{date_str}.json"

response = requests.get(url)
news_data = response.json()

for cve_id, articles in news_data.items():
    print(f"CVE: {cve_id} ({len(articles)} articles)")
    for article in articles:
        print(f"  - [{article['date']}] {article['title']}: {article['link']}")
SAMPLE JSON RESPONSE OBJECT:
{ "CVE-2026-63030": [ { "date": "2026-10-19", "title": "Critical RCE vulnerability discovered in enterprise gateway appliances", "link": "https://example.com/advisory/2026-63030" } ] }
